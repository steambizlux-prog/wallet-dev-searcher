DEV WALLET SEARCHER — КАК ЗАПУСТИТЬ
===================================

Что делает софт
---------------
Следит за свежими мигрейтами токенов (bonding curve -> DEX) на Pump.fun / StonkFun / Bonk.fun
через GMGN. У токенов, где Total Fees >= порога (по умолчанию 2 SOL), берёт кошелёк дева и
проверяет его историю: сколько токенов запустил и сколько из них мигрировало.
Если дев подходит (по умолчанию: мигрейтов >= 5 %, запусков <= 1000) — в Telegram
приходит сообщение с кошельком (копируется одним нажатием) и ссылкой на GMGN.
Все пороги меняются прямо в Telegram, без перезапуска.


Что понадобится (всё бесплатно)
-------------------------------
1) Токен Telegram-бота.
   В Telegram открыть @BotFather -> /newbot -> придумать имя и username (кончается на bot).
   Он выдаст токен вида 123456789:AAF...  — скопировать.

2) Ваш Telegram id (число).
   Открыть @userinfobot -> Start -> он покажет "Id: 123456789".

3) Ключ GMGN API.
   Нужен Ed25519 публичный ключ. Его сделает скрипт из комплекта (см. ниже),
   потом на https://gmgn.ai/ai создать API Key, вставив публичный ключ в форму.
   Получится ключ вида gmgn_...

4) Python 3.10 или новее (только для Windows; на Ubuntu ставится скриптом).
   https://www.python.org/downloads/ — в установщике ОБЯЗАТЕЛЬНО поставить галочку
   "Add python.exe to PATH".


ЗАПУСК НА WINDOWS
-----------------
1. Распаковать архив в любую папку, например C:\bots\wallet-dev-searcher.
2. Дважды щёлкнуть run_windows.bat (в Проводнике может называться просто run_windows,
   тип "Пакетный файл Windows"). Он создаст окружение, поставит зависимости (1–3 минуты)
   и откроет в Блокноте файл .env.
3. В .env вписать:
       TELEGRAM_BOT_TOKEN=токен из BotFather
       TELEGRAM_CHAT_ID=ваш id из userinfobot
       GMGN_API_KEY=пока оставить, заполним в шаге 4
   Сохранить (Ctrl+S), закрыть Блокнот.
4. Ключ GMGN: дважды щёлкнуть get_gmgn_key_windows.bat. Он сгенерирует пару ключей,
   скопирует публичный ключ в буфер обмена и откроет https://gmgn.ai/ai.
   На сайте войти, в форме создания API Key вставить ключ (Ctrl+V), создать.
   Полученный gmgn_... вписать в .env (открыть файл .env Блокнотом) в строку GMGN_API_KEY=.
5. Снова запустить run_windows.bat. В окне побегут логи, в Telegram от бота придёт
   "Dev Wallet Searcher запущен".
   Остановить: Ctrl+C или закрыть окно. Пока окно открыто — софт работает.

Проверить, что GMGN отвечает: check_api_windows.bat (покажет свежие мигрейты и их поля).


ЗАПУСК НА СЕРВЕРЕ UBUNTU (22.04 / 24.04)
----------------------------------------
Так софт работает круглосуточно и сам поднимается после перезагрузки.

1. Подключиться: в cmd на Windows   ssh root@IP_СЕРВЕРА   (ввести пароль).
2. Установить одной строкой (скопировать целиком, вставить, Enter):

   apt-get update && apt-get install -y git && git clone -b claude/zen-keller-nrxmt4 https://github.com/steambizlux-prog/wallet-dev-searcher.git /root/wallet-dev-searcher && bash /root/wallet-dev-searcher/deploy/install.sh

   Если вместо GitHub хотите использовать этот архив: загрузить его на сервер
   (scp wallet-dev-searcher.zip root@IP:/root/soft.zip), затем на сервере:
   apt-get install -y unzip && unzip -q -o /root/soft.zip -d /root/ && bash /root/wallet-dev-searcher/deploy/install.sh

   Если спросит "Which services should be restarted?" — просто Enter.

3. Вписать ключи:   nano /opt/wallet-dev-searcher/.env
   (вставка в окно — правой кнопкой мыши; сохранить Ctrl+O, Enter; выйти Ctrl+X)
   Ключ GMGN на сервере:  bash /opt/wallet-dev-searcher/scripts/gen_gmgn_keypair.sh
   — напечатает публичный ключ для формы на https://gmgn.ai/ai.

4. Запустить и смотреть логи:
   systemctl restart wallet-dev-searcher && journalctl -u wallet-dev-searcher -f
   (выйти из логов — Ctrl+C, бот продолжит работать)

Полезное:
   systemctl status wallet-dev-searcher          — работает или нет
   systemctl stop wallet-dev-searcher            — остановить
   systemctl start wallet-dev-searcher           — запустить
   bash /opt/wallet-dev-searcher/deploy/update.sh — обновить до свежей версии

ВАЖНО: один бот (один токен) не должен работать одновременно в двух местах
(на ПК и на сервере). Второй экземпляр будет падать с ошибкой Conflict.


НАСТРОЙКА В TELEGRAM (после запуска)
------------------------------------
Напишите своему боту:

   /status                  — работает ли сканер, счётчики
   /settings                — все настройки + кнопки +/-
   /set_fee 2               — минимальный Total Fees токена, SOL
   /set_migrate 5           — минимальная доля мигрейтов у дева, %
   /set_minmigrated 2       — минимум мигрейтов у дева в штуках (0 = не проверять)
   /set_mintokens 2         — минимум запусков у дева (отсеять девов с 1 токеном)
   /set_maxtokens 1000      — максимум запусков у дева
   /platforms pump stonk    — какие лаунчпады смотреть (pump, stonk, bonk)
   /platforms_seen          — под какими именами GMGN отдаёт лаунчпады сейчас
   /pause  /resume          — пауза / продолжить
   /check <кошелёк>         — проверить дева вручную
   /token <адрес токена>    — найти дева по токену и проверить
   /raw <адрес токена>      — сырые поля GMGN (сверить fee)
   /last                    — последние находки
   /test                    — тестовое сообщение
   /help                    — справка

Находки в канал (чтобы делиться с друзьями):
   1. Создать канал, добавить бота администратором с правом "Публиковать сообщения".
   2. Переслать боту в личку любой пост из канала -> нажать кнопку "Слать находки в этот канал".
   В канал уходят только находки. Управление и служебные сообщения — только в личке
   у тех, чьи id указаны в .env (TELEGRAM_ADMIN_IDS, если пусто — TELEGRAM_CHAT_ID).
   Вернуть в личку: /channel default


ЕСЛИ ЧТО-ТО НЕ ТАК
------------------
- Бот отвечает "Нет доступа. Ваш id: ...": впишите этот id в TELEGRAM_ADMIN_IDS в .env
  и перезапустите.
- В логах 401/403 от GMGN: неверный ключ, либо на сервере включён IPv6 (GMGN его не
  поддерживает), либо сбиты часы (нужна точность +-5 с, включите NTP: timedatectl set-ntp true).
- "TelegramNetworkError ... Server disconnected" в логах: Telegram на секунду оборвал
  связь, бот сам переподключается. Это нормально.
- "Conflict: terminated by other getUpdates": бот запущен где-то ещё. Остановите второй.
- Ничего не находит: посмотрите /status (сколько мигрейтов увидено, сколько отсеяно по fee).
  Пороги по умолчанию строгие; попробуйте /set_fee 1 или /set_migrate 3.
